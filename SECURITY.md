# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 2.5.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability in Decksmith (especially regarding local telemetry daemon endpoints or shell injection in scripts), please do NOT open a public issue.

Instead, please send an email to the maintainers or report via GitHub Private Vulnerability Reporting.
We appreciate your help in keeping Decksmith secure for all makers.
